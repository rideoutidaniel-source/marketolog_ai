# Telegram-бот: ассистент мебельного магазина

Что умеет:
- Каталог по категориям с ценами и описанием (из `catalog.json`)
- Оформление заявки: имя, телефон, комментарий, уходит админу в Telegram
- Доставка, оплата, гарантия, контакты
- AI-консультант: отвечает на свободные вопросы («диван в маленькую гостиную до 8 млн») строго по вашему каталогу (нужен `ANTHROPIC_API_KEY`)

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Узнайте свой ID у [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости и настройте окружение:

```bash
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN, ADMIN_ID, при желании ANTHROPIC_API_KEY
python bot.py
```

## Настройка под ваш магазин

Откройте `catalog.json` и замените название, контакты, условия доставки, категории и товары.
Для фото товара вставьте ссылку на изображение или Telegram file_id в поле `photo`.

## AI-консультант с фото, расчётом и чертежами

Нужен ключ `GEMINI_API_KEY` (бесплатный, aistudio.google.com) или `ANTHROPIC_API_KEY` (платно, тогда `pip install anthropic`).
С ключом бот:
- принимает фото стены, оценивает размеры, рисует схему и считает цену по прайсу из `pricing.py`;
- по просьбе присылает фото ваших работ из папок `photos/kitchen`, `photos/wardrobe`, `photos/other`;
- расчёт всегда называет ориентировочным (точную цену даёт менеджер после замера).

Цены меняются в `pricing.py`. Фото кладите в папки `photos/...` (jpg/png).
Бесплатный тариф Gemini: содержимое запросов может использоваться Google для улучшения продуктов.

На Termux перед `pip install` выполните: `pkg install python-pillow`
